# Privacy Policy

TabPilot processes your prompts to generate browser actions.

## Data Processed

- User prompts
- Conversation history sent for context
- Tab metadata needed for action planning
- Page content when the getPageContent action is used
- Provider settings and local memory preferences

## Third-Party Processing

If you select an external provider (OpenAI, Anthropic, or Google Gemini),
relevant prompt/context data is sent to that provider's API.

## Local Storage

Sensitive settings and memory are stored in extension local storage on the
current browser profile.

## What is Not Collected by This Project

- No external telemetry endpoint is run by this project itself
- No backend owned by this project stores your data

## User Controls

- Clear chats in the sidepanel
- Delete memories in the Memory view
- Remove provider API keys in settings
